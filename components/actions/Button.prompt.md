Use for any committed action in the DFNS product — Title Case command verbs only ("Create Wallet", "Send", "Apply").

```jsx
<Button leadingIcon={<Icon name="HeroiconsMiniPlus" size={16} />}>Create Wallet</Button>
<Button variant="secondary">Learn More</Button>
<Button variant="destructive" size="sm">Delete Wallet</Button>
```

Variants: default (purple gradient), secondary (cold grey), outline (2px purple), ghost (white + hairline), destructive. Sizes sm/default/lg/icon. Pass `state="hover"` or `disabled` for specimen rendering.
