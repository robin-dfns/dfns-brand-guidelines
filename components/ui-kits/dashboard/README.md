# DFNS Dashboard UI Kit (Rubik 2026)

Recreation of the 2026 dashboard shell and home/insights views from the "🧊 Rubik 2026" Figma file (Desktop-TO-MIGRATE frames `Main5`–`Main11`, `Data-Block`).

- `index.html` — interactive: sidebar navigation switches views, hoverable nav + buttons.
- `Shell.jsx` — top bar (logo, command-K search with pastel glow, account) + organisation sidebar (workspace selector, nav, Developers button).
- `HomeScreen.jsx` — portfolio hero panel, onboarding data blocks, section header.
- `InsightsScreen.jsx` — stat cards with mini charts (from the Data-Block frame).

Exact values from the file: page bg `#f0f1f4`, 12px outer padding/gaps, bars/sidebar `#e0e3f0` r8, content `#fcfcfd` r8, data blocks `#e0e3f0` r18, hero panel `#f0f1f4` r12 with `rgba(121,111,255,.3)` ring.
