The full glyph set from the file: Heroicons at four weights (`Micro` 16px, `Mini` 20px, `Outline` 24px, `Solid` 24px) plus six DFNS product marks (Asset, Attestation, Audit, Auth, Gate, Governance).

```jsx
<Icon name="HeroiconsMiniArrowsUpDown" size={20} />
<Icon name="Governance" size={24} />
```

Names are PascalCase: `Heroicons` + weight + glyph. Read `Icon.d.ts` for the complete list. Single-colour glyphs paint with `currentColor`; the DFNS marks carry their own purple fills.
