Resize the window PNG

Nothing to drag here — this canvas takes no pointer input on dfns.co either. What it does do is re-fit: resize the window and watch the landmass re-rasterise into the hexagon grid, which is the whole point of the treatment. Rendered bare and centered, so no location markers, no code window and no left-hand fade.
