Design System
Hex-dot map — home hero canvas
#hero-globe-canvas · world_map.glb
Slow loop · resize to re-fit PNG

The map is simply there from the first frame — rendered bare and centered, so none of the home-page overlay arrives on top of it: no location markers, no connection line, no code window, no left-hand fade. Two things loop: the shader's own per-hexagon pulse across the landmass, and a slow drift that traces a closed path every 80 s. Nothing to drag — this canvas takes no pointer input on dfns.co either — but resize the window and the landmass re-rasterises into the hexagon grid, which is the whole point of the treatment.
